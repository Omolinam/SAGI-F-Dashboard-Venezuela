# SAGI-F Dashboard – Riesgo Geopolítico y Economía de Venezuela

**Sistema Automatizado de Gestión Integral en Finanzas (SAGI-F)**

Dashboard interactivo bilingüe (Español / Inglés) diseñado para el seguimiento diario de variables clave que afectan la economía venezolana y su interdependencia con la geopolítica y economía mundial.

---

## 🎯 Finalidad

Este dashboard sirve para:

- **Toma de decisiones ejecutivas rápidas** y análisis técnico más profundo.
- Monitorear diariamente:
  1. Precios del petróleo (WTI / Brent) y licencias energéticas en Venezuela
  2. Tipo de cambio oficial (BCV) y paralelo
  3. Noticias globales de impacto en la economía venezolana
  4. Gacetas oficiales y cambios legales relevantes
  5. Implicaciones de riesgo y oportunidad para el sistema SAGI-F

Es una herramienta de apoyo para liquidez, tipo de cambio, sector petrolero, inflación y decisiones financieras de corto plazo.

## 🚀 Cómo usar el Dashboard

1. Abre el archivo `index.html` en cualquier navegador moderno.
2. Usa las pestañas superiores para navegar entre secciones:
   - 📊 Resumen
   - 🛢️ Petróleo & Licencias
   - 💱 Tipo de Cambio
   - 🌍 Noticias Globales
   - 📜 Gacetas & Legal
   - 📌 Implicaciones SAGI-F
3. Cada sección tiene botón **📋 Copiar** para exportar el texto fácilmente.
4. Los gráficos se generan automáticamente con Chart.js.

## 🌐 Publicar online (opcional)

Puedes activar **GitHub Pages** para tener un enlace público permanente:

1. Ve a **Settings → Pages**
2. En *Source* selecciona **Deploy from a branch**
3. Elige la rama `main` y la carpeta `/ (root)`
4. Guarda. En unos minutos tendrás el dashboard disponible en:

`https://omolinam.github.io/SAGI-F-Dashboard-Venezuela`
